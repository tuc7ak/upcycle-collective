Problem & Solution

The gap we're closing

Sustainability events preach — but don't incentivise. Crypto has power — but lacks accessible real-world utility. The Upcycle Collective bridges both.

❌ The Problem

Two broken systems

  • ❌ Sustainability events rely on goodwill alone — no real incentive to participate or donate
  • ❌ Crypto is perceived as speculative — most people have never used it for anything real
  • ❌ Micro-rewards on most blockchains are economically unviable due to high transaction fees
  • ❌ Community-scale financial inclusion experiments have no replicable open-source blueprint
✅ Our Solution

UPC Token on Solana

  • ✅ Real token rewards for real sustainable actions — donate a bag, earn tokens instantly
  • ✅ A live, hands-on crypto experience designed for non-technical first-timers
  • ✅ Solana's near-zero fees make 5–10 token micro-rewards economically viable at scale
  • ✅ Open-source model so any community globally can replicate this event
Why Solana

Built on Solana — not by accident

We evaluated multiple chains. Solana is the only one where the economics, speed, and developer ecosystem make this event model actually work.

⚡

Near-Zero Fees

Every token transfer — a donation reward, a trivia payout, a station purchase — costs less than a fraction of a cent. This makes 10-token micro-rewards economically viable. On Ethereum, the gas would cost more than the reward itself.

~$0.00025 per transaction
🚀

Real-Time Speed

400ms block finality means guests see their token balance update the moment they donate or spend — creating a seamless, real-time experience. Slow confirmations would break the event flow and confuse non-crypto users.

400ms finality
📝

Memo Program

Solana's native Memo program lets every transaction carry a human-readable label on-chain — "Donation · 1 bag", "Purchase · Upcycle Workshop". Guests see a clean, meaningful transaction history, not just wallet addresses.

On-chain transaction labels
🏗️

SPL Token Standard

The SPL token standard makes our UPC Token easy to integrate with existing Solana wallets, dApps, and infrastructure. No custom chain, no bridges — composable from day one.

Composable SPL token
🌏

Southeast Asia Ecosystem

Solana's growing presence in Malaysia and Southeast Asia — through Superteam and local communities — means we're building where the ecosystem is actively expanding. Kuching becomes a case study for the region.

Growing SEA ecosystem
🌐

Thriving Developer Ecosystem

Solana's mature developer tooling — Anchor, SPL, Helius, and the Superteam network — means we can build, test, and ship fast. The ecosystem support makes it the most practical chain for a community-first project like ours.

Mature tooling & Superteam support
Open Source Commitment

Built to be replicated

Open source is not part of Milestone 1. Our priority is to first prove the concept works — run the event, validate the token economy, and generate real on-chain data. Open source comes after, once there is something worth sharing.

🔗

UPC Token Contract

After Milestone 1 proves the token economy works, we will open-source the SPL token contract so any community can deploy their own version. Not in scope for M1.

Planned for Milestone 2
📱

Event Check-In System

The guest wallet and check-in system will be open-sourced after it has been tested in a live event. We want to share something that actually works, not an untested prototype.

Planned for Milestone 2
📖

Upcycle Collective Playbook

A full step-by-step guide for other communities to run their own edition. Written after M1 so it reflects real learnings from a live event — not assumptions.

Planned for Milestone 2
🌐

Why We Open Source Later

Open sourcing after validation — not before — means what we share is tested, useful, and replicable. This is a stronger contribution to the Solana ecosystem than publishing untested code.

Validate first. Share second.
